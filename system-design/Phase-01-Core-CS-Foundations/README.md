# Phase 1 — Core CS Foundations

> **Status:** Not Started

## Overview

This phase lays the bedrock for everything that follows. Before diving into distributed systems design or cloud-native .NET, you need a solid mental model of how programs work at the machine level — memory, data structures, and algorithmic thinking. These are the tools you'll reach for when debugging a performance problem, designing a cache, or analyzing a system bottleneck.

## Sections

1. [Programming Fundamentals](./01-programming-fundamentals.md)  
   Memory management, closures, concurrency basics, serialization, and the building blocks of all programs.

2. [Data Structures](./02-data-structures.md)  
   Arrays, hash tables, trees, heaps, bloom filters, ring buffers, and cache structures — how they work internally and when to use them.

3. [Algorithms](./03-algorithms.md)  
   Sorting, searching, graph traversal, dynamic programming, string matching, and complexity analysis.

## Learning Objectives

By the end of this phase, you should be able to:

- Explain the difference between stack and heap allocation and describe how GC works
- Implement common data structures from scratch and explain their time/space complexity
- Analyze the complexity of an algorithm using Big-O notation
- Choose the appropriate data structure for a given system design problem
- Recognize when a problem requires DP vs greedy vs backtracking

## Suggested Order

Work through sections in order (1 → 2 → 3). Programming fundamentals provide context for why certain data structure choices matter; algorithms section builds on data structure knowledge.
